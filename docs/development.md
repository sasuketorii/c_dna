# 開発・検証

このブランチでは要件定義 v1.0.0 に対応する実装を進めています。既存 README の設計説明は維持します。実装状況と実測結果は本書と受け入れ台帳を正本として追加します。

## 検証環境

会話内の作業環境は Linux x86_64 / Python 3.13.5 / Node 22.16.0 です。Rust コンパイラ、Python 3.14、Node の製品依存一式がプリインストールされていないため、対象依存の解決・コンパイルは GitHub Actions でも検証します。依存解決結果を確認し、lockfile と ADR に記録します。確認していない版や実行結果は完成扱いにしません。

macOS の配布署名・notarization は署名用資格情報と実機確認が必要です。外部 AI 認証を使った実接続、および本人の独立した判断再現評価も別ゲートです。

## デモ

公開デモは全て架空の経営ケースです。実際のチャット履歴は取り込んでいません。合成データに対する正しさの確認を、利用者本人への予測精度として表示しません。
