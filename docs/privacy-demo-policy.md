# 公開データの取り扱い

公開ソース、fixture、テスト、スクリーンショットは完全な架空データだけを使用します。ユーザーから匿名化したメモリ利用の許可はありますが、再識別のリスクを避け、実在する会話や顧客情報を変換して公開する方法は採用しません。

例に含めるのは一般化したトレードオフ（品質と納期、内製と外注、可逆な検証と投資など）のみです。氏名、住所、家族、健康、実際の取引条件、非公開の事業計画は使用しません。

`synthetic` はデータの由来を示します。架空問題に利用者が回答した場合でも、問題が実際に起きた出来事になったとは扱いません。ブラウザーデモで生成する回答を本人の確認済み観測として個人保管庫へ移送しません。
